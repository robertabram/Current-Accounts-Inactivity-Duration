# Current-accounts-inactivity-duration
Shows the average and total inactivity duration of current accounts, along with the associated balances (AMD,USD,EUR).


# Business Objectives
Analyze the average duration of inactive current accounts
Analyze the average amount stayed in current accounts during the idle period.
